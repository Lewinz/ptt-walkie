# ptt-walkie

灵矽语音对讲机 (PTT walkie-talkie on Lingxi AI)

面向司机（但不限于）的[灵矽 AI](https://xrobo.qiniu.com/#/agent-market) 应用：通过多种方式灵活建群，用嵌入式设备进行群语音对讲，并支持语音切换群（房间）。

- 控制面：灵矽智能体 + 本项目 MCP Server（建群、入群、切群、回放、摘要）
- 语音面：自建对讲转发服务（PTT、抢麦、Opus 实时转发）
- 管理面：小程序 / H5（扫码建群、车队管理）

详细需求、产品设计与实现路径见 [docs/requirements.md](docs/requirements.md)，黑客松范围与迭代计划见 [docs/hackathon-plan.md](docs/hackathon-plan.md)。
